### What's changed

- Settings now use native Service, Versions & Updates, and General groups, with wrapping descriptions and layouts checked in English and Chinese, light and dark appearances, and compact windows.
- DSH package downloads show real downloaded bytes and transfer speed. When the total size is known, they also show a percentage and estimated time remaining. Dependency installation shows its current stage, elapsed time, and expandable logs.
- Installation can be cancelled. Controls become available again after cleanup, and quitting DSH Bar waits for the installation task to finish cancelling.
- Installation feedback survives closing and reopening the dashboard or switching languages. The last 64 KiB of installation logs remain available after completion.
- The downloaded main package is pinned to the resolved version and checked against the registry's SHA-512 integrity value before npm runs.

### Installation behavior

The main DSH package downloads directly from the official public `registry.npmjs.org`, bypassing npm's main-package cache and custom registry, authentication, proxy, and CA settings. Dependencies still use npm's own configuration and environment. Use the terminal if your setup requires a private mirror or custom network configuration.

Cancelling or failing an installation does not roll back changes npm has already made. Installing a new CLI version does not automatically restart a running DSH service.
