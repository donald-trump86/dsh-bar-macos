What's changed

  • npm tag installation now shows an animated progress bar, the selected channel and elapsed time. The channel selector and install button stay disabled until installation finishes.
  • Installation feedback resumes when you reopen the dashboard and stays visible after a language change. Failed installations restore the controls and show an error.
  • Release builds now use the project's stable self-signing certificate. Future releases signed with this same certificate keep a consistent macOS permission identity. When upgrading from an older ad-hoc build for the first time, you may need to grant permissions again.
