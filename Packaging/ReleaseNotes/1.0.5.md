### What's changed

- Added a native English and Chinese permissions guide covering Full Disk Access, Automation, Photos, Media & Apple Music, and Local Network. Local Network privacy controls are available from macOS 15.
- The guide opens once on first launch and can be skipped by closing it or choosing Set Up Later. Reopen it at any time from Settings → Permissions & Access → Open Guide.
- Each section links to its System Settings page, falls back to the Privacy & Security homepage if opening fails, and provides a manual path when a link cannot locate the page. The guide scrolls in compact windows.

### Permissions remain under your control

The guide does not request or verify authorization. Check the actual requesting program listed by macOS; granting access to DSH Bar does not guarantee access for Node, Terminal or other processes. Opening Settings or dismissing the guide does not grant permission.

This release does not fix shutdown delays or change service lifecycle behavior.
